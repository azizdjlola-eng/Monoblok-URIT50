# Yangi laboratoriyaga o'rnatish va moslash

Dasturni yangi mijozga o'rnatganda hamma sozlash kod tegmasdan, dastur oynalaridan qilinadi. Eng oson yo'l — **O'rnatish ustasi**.

## O'rnatish ustasi

**Tizim Sozlamalari** → pastda **🧭 O'rnatish ustasi**. Mijoz versiyasida dastur birinchi ochilganda o'zi chiqadi.

Har qadam avtomatik tekshiriladi: ✓ tayyor, ⚠ albatta qarang, ℹ ma'lumot. Qadam yonidagi tugma tegishli sozlash oynasini ochadi. Sozlagach **↻ Qayta tekshirish** ni bosing. Hammasi tayyor bo'lsa — **✔ O'rnatish tugadi**.

| № | Qadam | Nima tekshiriladi |
|---|---|---|
| 1 | Baza ulanishi | baza manzili, katalogdagi tahlillar soni |
| 2 | Klinika ma'lumotlari | nom, manzil, telefon, laborant vrach, logo |
| 3 | Analizatorlar | model va ulanish; siydik analizatori yo'q bo'lsa — qo'lda rejim |
| 4 | Maxsus tahlillar | Umumiy qon / siydik va panellar katalogda topildimi |
| 5 | Panel a'zolari ID | Lipid / Buyrak paneli a'zolari to'g'ri tahlilga bog'langanmi |
| 6 | Kritik qiymat chegaralari | chegaralar katalogdagi to'g'ri tahlilga tushadimi |
| 7–9 | Blankalar | gemo, siydik, maxsus jadvallar — namuna bilan ko'rish |
| 10 | Printer va papkalar | printer, Word blankalar papkasi |
| 11 | Litsenziya | holati |

## Eng muhim uch narsa

**1. Maxsus tahlillarni katalogga bog'lash** — Tizim Sozlamalari → 🧩 Maxsus tahlillar.
Dastur Umumiy qon, Umumiy siydik, Bilirubin, Lipid, Buyrak, GTT, Revmoproba kabi tahlillarni nomi bo'yicha taniydi. Mijoz katalogida ular boshqacha nomlangan bo'lsa (masalan «OAK», «Общий анализ крови»), analizator natijasi bemorga **tushmaydi**. Shuning uchun bu tahlillarni shu oynada katalogdan tanlab bog'lang.

**2. Panel a'zolari ID lari** — Bioximiya → 🧾 Blanka ko'rinishi → Lipid / Buyrak varaqlari, «A'zo tahlil ID» ustuni.

**3. Kritik qiymat chegaralari** — 🧩 Maxsus tahlillar → 🚨 Kritik qiymat va signal chegaralari. «Katalogdagi nomi» ustunida ⚠ bo'lsa, bu ID mijoz katalogida boshqa tahlil. To'g'ri ID ni yozing yoki o'chiring.

## Boshqa sozlamalar (qisqacha)

- **Gemotologiya normalari (yosh × jins)** — Gemotologiya → 🧾 Blanka ko'rinishi → 📏 Normalar.
- **Maxsus jadvallar** (Nechiporenko, Spermogramma, Najas, Urologik surtma, GTT ...) — 🧩 Maxsus tahlillar → 📋 Maxsus jadvallar.
- **Koagulogramma va Bilirubin normalari** — «Tahlil Qo'shish» oynasidagi sub-normalardan olinadi.
- **Imzo rasmi, «Tasdiqladi» qatori, blanka izohi** — Blanka Sozlamalari → Klinika ma'lumotlari. Imzo — laborant vrachniki.
- **Kirill blanka** — Blanka Sozlamalari → 🌐 Blanka tili → O'zbekcha yozuv: Kirill. Tahlil kodlari (WBC, HGB ...) lotincha qoladi. Klinika brendini lotincha qoldirish uchun uni «Lotincha qoladigan so'zlar» ga yozing.

## Sozlamalar qayerda saqlanadi

Blanka va tahlil sozlamalari **bazada** saqlanadi, shuning uchun laboratoriyaning hamma kompyuterida bir xil bo'ladi. Baza ishlamay qolsa, kompyuterdagi oxirgi nusxa ishlatiladi. Ulanish sozlamalari (IP, COM port, papkalar, printer) esa har kompyuterning o'zida.
